    发送 yaw、pitch
    shoot 根据火控结果决定

计划无效：
    保持当前云台角度
    shoot = false
    加rejection reason

Plan 无效
    → 保持当前角度

Plan 有效且 using_MPC == false
    → 使用 plan.yaw / plan.pitch

Plan 有效且 using_MPC == true
    → 使用 plan.samples.front().yaw / pitch

using_MPC == true 但 samples 为空
    → 按无效规划处理
