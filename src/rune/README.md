检测关键点 → 筛选轮廓 → 重建三维旋转平面 → 估计叶片相位与运动 → 预测弹丸到达时的靶心 → 输出云台角度和开火许可
f1-detection 神经网络检测关键点，将识别到的有效画面进行切割并提取到检测区 
f2-reobservation  提取可用的二维特征，在检测区域内按红蓝颜色差提取轮廓，再利用关键点约束，识别装甲板、灯臂和中心 R 标。它还检查轮廓是否适合后续投影，并根据输入模式和class_id标记大符或小符、未激活或已激活 
f3-building 重建三维目标与旋转平面，将提取出来的二维特征与模型进行比对，构建出能量机关完整形态，再将模型上的符心、靶心位姿转换成云台坐标系
f4-estimator 根据大小能量机关套用不同的运动模型，拟合出最佳运动模型估计叶片相位与运动
f5-planning 预测弹道落点并输出云台角度，单发开火许可
