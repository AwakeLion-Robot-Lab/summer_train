# 关键点持续抖动的修正

本次针对关键点定位波动，保留当前 GPU、0.4/0.4 门限、满幅输入和关闭尺度回退
的配置。测试前已有候选融合和图像精修；本次修改继续处理这些步骤之后的残差。

## 修改

图像精修原先把滤波输出同时用于下一帧的关联、配准区域和坐标传递。
这样滤波强度会影响下一帧裁剪区域，临界情况下配准失败会直接跳回网络坐标。
现在保留原始观测历史确定关联及配准区域，另存滤波坐标用于运动传递。

ECC 先沿用单位变换初始化，失败时以原始观测位移重试一次。
仍失败时，使用局部角点的双向 LK 跟踪：至少六个可靠点，前后向误差不超过
0.5 像素、LK 灰度误差不超过 15，RANSAC 内点至少占有效点的 80%，
并检查尺度及 R 区域的转动。坐标传递仍受现有图像边界和逐点几何门限约束。
两种图像测量都不可信时保留当前网络坐标。

项目 YAML 的 `rune.image_refiner.measurement_time_constant_s` 从 0.08 调为
0.16。先用图像运动传递上一帧坐标，再平滑当前网络观测与传递坐标之间的残差。
该参数不是将靶面运动直接延迟 160 ms；合成连续平移测试检查了运动响应。
无检测、弱点、长时间断流、模式和颜色切换仍遵守原有处理约定。

实机每秒诊断增加 `image_refined_r` 和 `image_refined_targets`，分别表示当前帧
实际完成精修的 R 点数及靶板数，便于确认精修是否生效。

## 完整录像对照

同一 GPU、模型、满幅输入、门限及候选融合设置。对照包含旧精修实现和 0.08 s
参数；修改后使用新实现和 0.16 s。录像分别为
`2026-10-28_00-03-18.avi`（大符入口）和 `2026-10-28_00-05-41.avi`（小符入口）。
总计 1843 / 798 帧，检出帧数保持 794 / 258，逐帧检测数量均未变化。

使用 `tools/rune/compare_keypoints.py` 以相同帧对及相同独立 ECC 变换评估，
数值均为原图像素下扣除图像运动后的帧间残差。

| 指标 | 大符修改前 → 后 | 小符修改前 → 后 |
| --- | ---: | ---: |
| R 残差 P95 | 0.589 → 0.365 | 0.713 → 0.455 |
| 靶心残差 P95 | 0.580 → 0.330 | 0.613 → 0.415 |
| 四靶板点残差 P95 | 0.671 → 0.394 | 0.661 → 0.461 |
| 四靶板点残差 RMS | 0.349 → 0.205 | 0.372 → 0.254 |
| 四靶板点最大残差 | 1.922 → 1.105 | 1.191 → 0.943 |

R 的有效帧对为 561 / 220，靶板为 561 / 143。部分点、目标切换和独立 ECC
相关性不足 0.98 的帧对不计入统计。这不是人工标注的绝对定位误差，也不能
证明不存在固定偏差或代表所有远距离实机画面。修正量最大的样本也进行了目视检查。

两次顺序回放的检测加精修平均时间为大符 12.12 → 10.15 ms、小符
11.95 → 11.02 ms；设备负载有波动，不能据此宣称性能加速。光流仅在 ECC
失败时运行，没有新增模型推理。

配置、完整检测日志、最大修正样本及统计 JSON 位于 `build/rune_detection_audit/`。
例如：

```bash
python3 tools/rune/compare_keypoints.py \
  --video video/rune/2026-10-28_00-05-41.avi \
  --before build/rune_detection_audit/small_baseline_full.log \
  --after build/rune_detection_audit/small_stabilized_full.log \
  --output build/rune_detection_audit/small_stabilization.json
```

`rune_image_refiner_smoke` 覆盖静止噪声、快速与连续平移、小尺寸目标、局部外观
变化、弱点、空白图、目标切换、断流及无串口反馈。
