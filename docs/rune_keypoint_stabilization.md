# 关键点持续抖动的修正

图像防抖保留原始观测历史确定关联及配准区域，另存滤波坐标用于运动传递。

ECC 先沿用单位变换初始化，失败时以原始观测位移重试一次。
仍失败时，使用局部角点的双向 LK 跟踪：至少六个可靠点，前后向误差不超过
0.5 像素、LK 灰度误差不超过 15，RANSAC 内点至少占有效点的 80%，
并检查尺度及 R 区域的转动。坐标传递仍受现有图像边界和逐点几何门限约束。
两种图像测量都不可信时保留当前检测坐标。

项目 YAML 的 `rune.image_refiner.measurement_time_constant_s` 为 0.16。先用图像运动传递上一帧坐标，再平滑当前观测与传递坐标之间的残差。
该参数不是将靶面运动直接延迟 160 ms；合成连续平移测试检查了运动响应。
无检测、弱点、长时间断流、模式和颜色切换仍遵守原有处理约定。

实机每秒诊断增加 `image_refined_r` 和 `image_refined_targets`，分别表示当前帧
实际完成精修的 R 点数及靶板数，便于确认精修是否生效。

两份 `rune_detect` 日志可用 `tools/rune/compare_keypoints.py` 比较。工具用一致的帧对和独立 ECC 变换计算扣除图像运动后的帧间残差，单位为原图像素。部分点、目标切换和 ECC 相关性不足 0.98 的帧对不计入统计。

`rune_image_refiner_smoke` 覆盖静止噪声、快速与连续平移、小尺寸目标、局部外观
变化、弱点、空白图、目标切换、断流及无串口反馈。
