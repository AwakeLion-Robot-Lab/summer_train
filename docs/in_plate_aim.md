# 板内动态瞄点

策略入口为 `queryInPlateAim()`，位于整车预测之后、弹道求解之前。`ArmorPose.position_world` 始终是实体板心；`ArmorCandidate.aim` 和 `AimPlan.aim_point_world` 才是板内瞄点。`ArmorPose.rotation_world` 的三列依次是朝车心的法向、板宽 u、板高 v；ESKF 路径直接使用整车 SO(3) 模型的装甲板位姿，包含车体倾斜和装甲后仰。纯数值兼容路径使用 yaw 和标准后仰角。

`config/planner_config.yaml` 的 `in_plate_aim` 提供三个对照模式：

- `center`：保持板心。
- `fixed_diagonal`：沿板内对角线的单一进度运动。
- `independent`：横向延续当前枪口运动，纵向预调接替板高度。

`enable: false` 也保持板心。代码默认关闭，仓库运行配置启用 `independent`。动态模式的离线验证显式启用 `independent`，不依赖运行配置。开关控制板内偏移，开火误差始终以当前瞄准指令为基准。

## 允许移动的区域

有效半宽/半高取受击面尺寸乘 `hit_margin_ratio / 2`，扣除 `edge_margin_m` 和 `uncertainty_sigma` 倍的位置标准差，再按正对程度缩小偏移范围。完整 ESKF 路径由实体板心对误差状态的雅可比投影协方差，保留位置、SO(3)、半径、高度之间的交叉项；数值兼容入口用保守近似。目标刚初始化时等待 `warmup_frames` 个新观测，预测不确定度过大时退回中心。安全范围突然收缩时立即裁剪到安全边界，这种情况下安全边界优先于速度/加速度限制。

当前小板宽 135 mm、大板宽 230 mm、高 125 mm，使用中心 60%，另留 5 mm 边缘余量。这些值沿用原火控，**需要按实际有效受击区确认**；视觉解算的灯条高度 56 mm 不用于这里。L5 保留自己的尺寸配置，角度容差按 L4/L5 较小的有效尺寸换算，再与配置中的角度下限取较大值。调整受击面尺寸时应同步检查 `config/auto_aim.yaml` 的 `fire` 配置。

`edge_margin_m` 只限制瞄点可移动范围。当前小板有效半宽为 40.5 mm、半高为 37.5 mm；瞄点偏移先扣 5 mm，再扣预测不确定度并按正对程度缩小。开火角度容差不再次扣除该边距，也不扣除瞄点相对板心的偏移。

## 运动与时间

横向根据板心相对枪口的视线运动和上一帧反馈估计的枪口 yaw 速度，在安全区域内选择延续枪口运动的位置。纵向按旋转方向找到下一块接替板，预测它到达当前相位的高度，最多提前 0.5 s；有效高度重叠时取共同高度，否则逐渐向下一板靠近。换板起点尽量保持上一瞄点的世界高度。u/v 独立限速、限加速度；近零旋转和反向使用进入/退出双阈值。

弹道固定点迭代每次都从同一跨帧快照查询瞄点。偏移运动按发射/控制时刻推进，不能用每次变化的命中时刻推进跨帧状态。只有选板成功且收到新观测后提交一次偏移、速度、旋转方向和反馈角；目标重置或更换时清空快照。最终板姿态、瞄点和飞行时间在配置收敛误差内对应同一时刻。

MPC 的每个参考采样点代表一个发射时刻，独立迭代对应的命中时刻。中心采样与直接瞄准共用同一求解入口和旧快照；未来采样在当前板离开保持窗口后预测接替板。该局部选板不修改 Planner 的跨帧锁板状态。参考可在两板之间跳变，由 MPC 生成满足加速度约束的运动；控制层每帧检查实际反馈相对当前执行采样的角度误差。

## 前哨站三板

前哨站使用三板模型和各自的 `three_armor_height_offsets[0/1/2]`，相邻板相差 120°。正向旋转的接替顺序为 0 → 2 → 1 → 0，负向为 0 → 1 → 2 → 0（板号定义沿 yaw 正方向递增）。普通车辆仍按四板 90° 循环。前哨站的前倾角直接取共用的 `armorPitchOf(Outpost)`，与 ESKF 和火控板面一致。协方差投影遵循前哨只绕竖直轴旋转的模型，不把无关的 roll/pitch 方差计入板心误差，避免可移动范围被过度压缩。

`independent` 模式下，`in_plate_aim.outpost.prefer_common_height: true` 优先计算三块板都能接受的高度。比较时把三块板放到相同面向角，避免把尚在背面或侧面的板当成没有可用高度；每块板仍按自己的高度和协方差扣除安全余量。三板存在共同高度时向该区间中点平滑移动，减少一圈内反复升降；没有三板交集时退回当前板与下一板的重叠高度，两板也无交集时只向下一板靠近，并限制在当前板内。设为 `false` 可对照原来的两板高度预调。

MPC 的未来采样优先按旋转方向接替，跟踪尚未进入窗口的新板时不继续跳向第三板。三板选板窗口之间可能存在空隙，参考可提前指向接替板；实际开火仍要求当前计划放行，且反馈相对当帧指令的 yaw/pitch 误差分别满足容差。前哨站始终使用三块候选板。

```sh

build/linux/x86_64/release/outpost_aim_smoke
```

覆盖正反向 120° 接替、三个独立板高、三板共有高度与两板回退、初始化/不确定度回退、前倾板面、协方差投影的几何数值差分核对、弹道收敛、MPC 中心一致与循环换板、瞄点误差超限禁火和不存在板号的拒绝。

## 开火判定

L5 分别计算实际反馈 yaw/pitch 与当前瞄准指令的绝对角度误差，yaw 跨 ±π 时归一化。直接瞄准使用 `plan.yaw/pitch`；MPC 使用 `plan.samples.front().yaw/pitch`，与控制层本帧输出一致。启用误差禁火时，两轴误差必须分别不超过允许容差，不能用其中一轴抵消另一轴。

允许容差以当前瞄点为中心对称计算：用有效板宽/高、朝向和瞄点距离换算几何角度，再分别与 `min_yaw_tolerance` / `min_pitch_tolerance` 取较大值。板内偏移不扣减容差。运行配置的下限为 yaw 2°、pitch 1.8°。

`config/auto_aim.yaml` 的装甲板 `fire` 提供两项独立开关，代码默认均为 `true`，当前运行配置按实机要求均设为 `false`：

- `stop_fire_on_aim_error`：关闭后，有限的 yaw/pitch 跟随误差超限只作诊断，不再产生 `aim_error` 拒绝。
- `stop_fire_on_temp_lost`：关闭后，`TempLost` 不再单独禁火。若目标仍存在、规划有效、选板已处于 `Tracking` 且仍在射击窗口内，也不会因缺少新观测导致的 `tracked_ready=false` 间接禁火。

目标完全丢失、尚未确认、规划无效、尚未锁稳或正在换板、离开射击窗口、反馈非有限值、总开火开关、有效弹速和命令连续性门控仍参与最终判定。这两项开关只作用于装甲自瞄，不改变能量机关的独立火控。

`FireDecision.aim_error_within_tolerance` 表示本帧角度误差是否通过。`predicted_hit_uv`、`predicted_fly_time` 和 `hit_inside_plate` 继续记录按实际反馈推算的板面交点，仅供诊断，不参与开火放行；因此 `hit_inside_plate=false` 可以与 `shoot=true` 同时出现。终端日志使用 `aim_ok` 和 `plate_hit_diag` 区分这两项。

开启 `debug.overlay` 或 `debug.plot` 时，终端每秒汇总 `fire gate stats`：`allow_pct` 是本段规划帧的开火放行比例，`unlocked_pct` / `outside_window_pct` 分别统计锁定未就绪和窗口未通过，`reject_counts` 展开所有拒绝原因及其帧数（同帧可计入多个原因）。同时记录处理 `fps` 与实际串口发送 `serial_tx_hz`，用于区分门控频繁断火、处理帧率不足和发送频率异常。规划帧放行比例不等于实际弹频；装甲自瞄以持续电平发送开火位，实际发弹节奏由下位机执行。

```sh
xmake build -y in_plate_aim_smoke
build/linux/x86_64/release/in_plate_aim_smoke
```

专项测试包含初始化与关闭回退、重复查询、完整板面偏移、侧对与协方差收缩、速度/加速度、旋转滞回、重叠/不重叠高度、对角线、换板高度、弹道时刻一致性、MPC 中心一致性与未来换板，以及真空/阻力模型下偏心瞄准、逐轴误差边界、yaw 跨界归一化、MPC 执行指令、偏移不缩小容差和配置容差下限。实际云台运动改善与命中率仍需在相同目标回放/实车条件下比较三个模式。

本机合成工况（目标旋转 3 rad/s、阻力系数 0.5/s、板内策略完成预热）连续运行 30 次，100 点参考加 MPC 平均约 6.5 ms，30 次均采用 MPC 输出。该数字仅作本机合成测试记录，实际帧率仍需结合真实目标状态和整条流水线测量。
