# 云台不同初始角与偏转角的阶跃响应采集

`gimbal_step_csv` 直接使用自瞄模式的串口协议：上位机通过现有
`SerialProtocol::encodeCommand()` 发送 `0x0001` 控制帧，`yaw`、`pitch`
为世界系绝对角（线上的单位是 rad），`shoot` 始终为 0；从现有
`SerialProtocol::feed()` 解析下位机 `0x0002` 状态帧。没有新增串口结构体、
帧 ID 或下位机固件要求。运行时必须独占串口，先停止 `auto_aim`。

## 运行

确认云台附近没有障碍、射击机构已禁用，并按实机软限位填写 `--limits`。
先测**一组角度**。以下命令表示：测 yaw，从 0° 出发偏转 +10°，
目标角为 +10°，重复 5 次，每次记录 2 秒：

```bash
xmake build gimbal_step_csv
xmake run gimbal_step_csv --axis yaw --initial-deg 0 --offset-deg 10 \
  --repeat 5 --limits "-45:45" --duration-ms 2000 \
  --port /dev/ttyACM0 --baud 115200 \
  --output /tmp/gimbal_yaw
```

无 `--arm` 时只打印初始角、偏转角、目标角和重复次数，不打开串口或移动云台。
核对后在命令末尾加 `--arm` 执行。首次实测建议先用 `--repeat 1` 和较小偏转角。
测 pitch 时把 `--axis yaw` 改为 `--axis pitch`，并填写 pitch 适用的角度和限位。
另一个轴会保持每次试验开始时上报的实际角度。

| 参数 | 含义 |
| --- | --- |
| `--axis yaw\|pitch` | 选择测量轴。 |
| `--initial-deg 0` | 本组试验的初始绝对角，单位度。 |
| `--offset-deg 10` | 相对初始角的偏转量，单位度；目标角 = 初始角 + 偏转角。负值表示反方向。 |
| `--repeat 5` | 同一组角度重复 5 次，默认 1 次。 |
| `--limits "-45:45"` | 测量轴允许的最小、最大角度；程序检查初始角和目标角。 |
| `--duration-ms 2000` | 发出目标命令后的观测窗口，接受正整数 ms，默认 2000 ms；只测响应启动延迟时可用 20、50 等短窗口。 |
| `--onset-threshold-deg` | 固定响应位移阈值（正数，度）；比较不同步长时应统一设置。省略则沿用 `max(0.5°, 5%×步长绝对值)`。 |
| `--port`、`--baud` | 串口设备与波特率，默认 `/dev/ttyACM0`、115200。 |
| `--output` | 四个 CSV 文件的路径前缀，必须填写。 |
| `--arm` | 真正执行试验；缺省仅预览。 |

要批量测多组角度，再把单组参数换成列表。下面是 3 个初始角 × 4 个偏转角 ×
5 次重复，共 60 次；偏转角正负两个方向都测：

```bash
xmake run gimbal_step_csv --axis yaw --initials "-30,0,30" \
  --offsets "-10,-5,5,10" --repeat 5 --limits "-45:45" \
  --duration-ms 2000 --output /tmp/gimbal_yaw_grid
```

旧参数 `--deltas`、`--repeats` 仍可分别代替 `--offsets`、`--repeat`。
单组参数和列表参数不能混用。`xmake run` 不需要额外的参数分隔符 `--`；
程序也接受字面量 `--`。

程序只接受下位机上报的 `AutoAim` 模式。每组先以 200 Hz 连续下发初始绝对角，
待反馈角进入 ±1° 并保持 300 ms；再记录 500 ms 基线，随后下发目标角并记录
默认 2000 ms 的响应。无法在 `--settle-timeout-ms`（默认 5000 ms）内稳定、
失去自瞄模式、串口读写失败或基线状态帧太少时停止并保留已完成的 CSV。
阶跃窗口不要求至少 10 个样本。每次直接打印响应启动延迟、判定阈值和反馈样本数；
没有反馈或窗口内未达到阈值时打印“未测到”，CSV 的 `onset_ms` 留空。
批量试验顺序使用固定种子 `20261021` 打乱，以减少温度、供电和方向顺序的偏差。

`--initials`、`--offsets`、`--limits` 和输出 CSV 均以度为单位；目标角等于
初始命令角加偏转角。程序在开串口前检查所有初始角和目标角都在给定限位内。
运行中按 Ctrl-C 停止；下位机原有的命令超时处理会保持最后角度并禁止射击。

## CSV

假设 `--output /tmp/gimbal_yaw`，产生以下文件：

| 文件 | 内容 |
| --- | --- |
| `/tmp/gimbal_yaw_samples.csv` | 每条反馈的原始曲线；`phase=baseline` 的 `t_ms` 为负值，`phase=step` 从第一条目标命令开始计时。包含命令和实际 yaw/pitch。 |
| `/tmp/gimbal_yaw_trials.csv` | 每次试验的启动时间、10%～90% 上升时间、稳定时间、超调量、最终角误差。无有效测量的指标留空。 |
| `/tmp/gimbal_yaw_model.csv` | 按“初始命令角 × 偏转角”分组，对上述指标取重复试验的中位数；这是经验查表模型。 |
| `/tmp/gimbal_yaw_curve.csv` | 同一分组下每 10 ms 的中位数响应曲线，含归一化进度和实际角度；不同试验的反馈点先做线性插值。 |

启动时间以实际角首次沿命令方向离开基线至少 `max(0.5°, 5%×偏转角绝对值)` 定义。
指定 `--onset-threshold-deg` 时用该固定阈值代替。固定起点、多步长各 500 次的
弧度参数示例及调参说明见 [gimbal_latency_example.md](gimbal_latency_example.md)。
稳定时间以进入 `max(0.2°, 2%×偏转角)` 误差带、此后持续在带内至少
100 ms 定义。yaw 误差使用最短圆周差。空值表示在采样窗口内未达到条件，
不能当作 0 ms。`_model.csv` 和 `_curve.csv` 给出经验查表模型，
不是传递函数的参数拟合。

## 时间口径与适用范围

只测控制响应延迟时，重点读取 `_trials.csv` 的 `onset_ms` 和终端的“响应启动延迟”，
不需要等到目标角或满足稳定时间条件。短窗口未测到不能当成 0 ms，也不一定是丢包；
应延长窗口确认响应是否晚于窗口。分组中位数只包含测到响应的试验，不能忽略未测到的次数。
`serial_rtt` 用 token 匹配 Ping/Pong，测通信往返时间；本工具用角度变化作为响应证据，
测的是包含机械起动及角度阈值跨越时间的反馈延迟，并非命令接收确认延迟。

`t=0` 是上位机开始写第一条目标控制帧的 `steady_clock` 时刻；反馈时间是
现有协议解析完状态帧时在上位机打的 `steady_clock` 时刻。因此 CSV 表示
“上位机下发到收到状态反馈”的闭环观测，包含发送调度、USB/串口、下位机控制、
状态上报和接收调度。现有状态帧没有 MCU 执行时间戳、编码器采样时间戳或命令
序号回显；这些量不能从 CSV 拆出来，串口 RTT 也不能直接除以二来校正。
若后续要识别纯下位机控制器的死区时间和机械动态，应在下位机同一时钟下记录
命令生效时刻与实际编码器角，再与本 CSV 对比。
