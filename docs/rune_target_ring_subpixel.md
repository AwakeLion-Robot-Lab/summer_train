# 外圈亮带中心线的亚像素精修

在已有圈层约束之后，用原图亮度剖面细化外圈坐标，降低光晕、曝光和二值化极值
对拟合尺寸的影响。工程已开启：

```yaml
rune:
  detector:
    lock_target_ring: true
    target_ring_subpixel: true
```

设 `target_ring_subpixel: false` 恢复原有外圈测量及图像精修路径，仍保留圈层约束。

## 单帧测量

原来的颜色分割、闭运算、凸包椭圆和尺寸门限继续确认圈层。精修只在已经通过
检查的外圈附近进行：

1. 在椭圆周围取 128 条法线，以 0.5 原图像素间距采样；内侧搜索 4～12 px，
   外侧搜索 2～5 px，搜索范围随靶板尺寸变化。
2. 用原始红/蓝较亮通道测量亮度，用红蓝差验证局部发光颜色。法线旁的三个剖面
   做轻度切向平均，保留饱和白核及其有色侧翼的观测。
3. 保留有足够局部突出度、颜色和宽度支持的亮峰。分别估计两侧背景与半高位置，
   线性插值得到两个亚像素边缘，再取中点作为亮带中心。
4. 一条法线上可能同时有灯臂、内部灯带与外圈，保留候选后选取中心点集的外侧
   支撑点。凸包在这里仅选择已测得的中心点，拟合输入为浮点中心线坐标。
5. 做四轮基于几何距离和 MAD 的异常点剔除，再拟合椭圆。要求原始中心线候选
   至少 40 个并覆盖 24/32 个圆周区间，外侧支撑点至少 12 个，剔除后至少保留
   70% 支撑点和足够的圆周分布。

最后检查拟合残差、中心移动、轴长与面积变化，以及原来的物理尺寸比例。
精修信息不足、形状退化、异常点过多或 OpenCV 拟合失败时，保留已确认的旧外圈。
不提高弱点可靠性，不改变 R、类别、网络分数或推理次数。

## 精修与回退的连续维护

单独逐帧切换“亮带中心线”和“粗轮廓”会制造小幅坐标台阶。实际录像验证了
这个问题，因此最终实现把精修测量与连续维护一起接入 `ImageRefiner`：

- 保留本帧粗外圈，作为关联、配准 ROI 和物理圈层变化检查的统一参考。
- 原有粗圈路径继续独立跟踪中心及两条语义方向，沿用普通测量的时间常数。
  亮带精修更新中心的小幅校正量及两对点的半径，以 0.5 s 时间常数校正残差；
  真实平移、旋转和缩放先由图像运动补偿。
- 精修点的方向始终取粗圈跟踪方向，防止 LED 动画的旋转在配准中累积为额外的
  语义方向漂移。中心校正限制在较短粗圈直径的 5%，半径限制在对应粗圈半径的
  0.88～1.04 倍。旋转光纹而保持几何观测固定的回归测试验证了这一约束。
- 暂时精修失败时，只有本帧仍有可靠靶板检测、粗外圈通过校验且图像配准通过，
  才传递精修点。距离最后一次精修测量不能超过现有 `max_gap_s`（工程 0.2 s），
  不用回退帧延长这个期限。
- 精修长期不可用、配准不可用或首次观测缺少精修时，使用原有粗轮廓路径。
  空检测不生成任何靶板点；上下文变化和显式 reset 清空精修历史。
- 内外圈变化继续按图像传递后的粗外圈直径检查。精修连续维护不能掩盖实际换圈，
  这在带有粗外圈元数据的专项测试中验证。

`ring_subpixel` 表示检测阶段实际完成单帧精修的候选数，短时传递不增加这个计数。

## 2026-11-14：断续 LED 外圈误拒绝修复

现场保存的 `logs/rune_input.png` 可稳定复现：网络置信度 0.933，五个点分数接近 1，
但 `ring_reject=1`、`valid=00001`。外圈存在几处暗间隙，原来的 5 px 闭运算没能
连接各段 LED；各段单独拟合均不能通过外圈尺寸检查。

现在仅在原有检查找不到合格外圈时，增加一次有界闭运算重试。原有核直径为
`max(3, 2*floor(0.06*r)+1)`，重试为
`max(原核直径+2, 2*floor(0.10*r)+1)`，`r` 为物理尺寸比例估计的像素半径。
现场图重试核为 9 px。物理尺寸、拟合残差、中心位置、填充率和至少 24/32
圆周区间支持的检查全部保留，支持率仍取闭运算前的亮点。合格后继续使用现有
亚像素精修及跨帧检查；原有第一次拟合成功的图像不会进入重试。

新增诊断：`ring_reconnect` 为通过重试恢复的外圈数，是 `ring_ok` 的子集；
`ring_no_contour` 为找不到合格图像外圈导致的拒绝数，是 `ring_reject` 的子集。
其他拒绝可来自可靠点不足、R 无效、方向或输出越界；接口另返回具体拒绝原因。

同一现场图修复后为 `ring_ok=1 ring_reject=0 ring_reconnect=1 valid=11111`，
目视核对四个靶板点位于外圈。该图单帧亚像素证据不足，`ring_subpixel=0`，
使用已经通过校验的粗外圈，不将缺少精修证据判成整个目标失败。

五项 smoke 和主程序、检测工具、大小符回放入口均通过构建/测试。新增红蓝稀疏
LED 回归，覆盖网络大小圈切换和精修开关；原有半圈遮挡、只有内圈、实心光斑、
灰色反光、弱点、错误 R 和越界测试继续拒绝。中心线理想模型误差保持原值。

## 验证

`rune_target_ring_smoke` 的独立合成图以已知 LED 中心为真值，包含高斯光斑、
曝光变化、饱和白核、局部白斑、亚像素移动和倾斜椭圆。12 个场景、48 个靶板点，
粗外圈平均绝对误差为 **2.427 px**，精修为 **0.032 px**，12 个场景均实际启用精修。
这证明了该理想成像模型中的光晕偏差改善，不代表实机绝对定位误差。

另覆盖更亮的邻近内圈、相连的彩色突出物、光度证据不足时精确回退、精修/回退
交替时的真实运动、缩放、精修过期、实际换内圈的拒绝及拒绝后的恢复。
`rune_target_ring_smoke`、`rune_detector_smoke`、`rune_image_refiner_smoke`、
`rune_partial_keypoints_smoke`、`rune_tracking_continuity_smoke` 均通过。
实机主程序、检测工具和大小符回放入口均构建通过。
关闭开关后，当前二进制前 100 帧的坐标、类别和有效性与改动前二进制逐项一致。
