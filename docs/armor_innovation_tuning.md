## 2026-11-09：持续旋转后的切板纵向回拉

**状态：降噪声方案已撤回。** 用户反馈真实变化响应明显过慢、效果不如原来，
YAML 和代码默认值均已恢复为 `roll_pitch_noise: 0.1`。完整角点投影与诊断工具
继续保留。以下是已撤回试验的记录，表中“新”不代表当前配置。
这次试验降低了回拉指标，但没有满足响应速度要求，不能作为切板问题的最终修复。

完整角点投影修正后，在本地 `3m_high / 3m_mid / 3m_low` 仍可复现：同一块
物理板再次进入观测时，更新前绿框纵向位置有系统偏差，收到观测后突然回拉。
高速录像稳态高度差参数未被反复清零。对照支持的解释是：单板观测下，整车高度、
板间高度差和倾斜存在耦合；过大的 roll/pitch 随机游走允许当前可见板把整车倾斜
拉偏，暂时不可见的板因而预测不准。这不是现场全部抖动原因的证明。

试验曾将 YAML 和 `VehicleModel::NoiseConfig` 默认 `roll_pitch_noise` 从 `0.1` 改为
`0.001 rad²/s`，其协方差增量为 `dt * noise`。在 50 Hz 下，每步噪声标准差
从约 2.56° 降到 0.256°。这是估计参数调整，会影响后续规划使用的状态；
保留各板真实高度差及完整姿态投影，没有对最终绿框坐标另加平滑。

`track_diag` 新增 `height_switch.csv`，每行对应实际关联到的完整物理板。
`obs_v` 是四个观测角点的平均纵坐标，`prior_v = obs_v - mean(dv)` 使用本帧
滤波器真实端点创新，`posterior_v` 使用完整姿态投影；
`correction_v = posterior_v - prior_v`。同时记录 z、板间高度状态和旋转向量 x/y
分量（不是欧拉角）。`overlay.csv` 的板框中心也改为完整姿态投影。

验证使用当前相机标定、`szu-v5n.xml`、GPU、全图检测，与回放入口一致。
高速取前 1600 帧，中速/低速分别完整读取 1100 / 1047 帧。
三段旧/新参数的 `obs.csv` 字节一致，检测输入没有变化。

## 降权规则

每个灯条观测有四维像素端点。在更新前计算 r 和 S=HPHᵀ+R，分别对上下端点的二维边缘分布计算 NIS。使用先验值，不拿迭代后的残差决定权重。

- `robust_corners: true`：收敛后启用端点降权；初始化阶段只记录，避免初始状态误差抑制正常收敛。
- `corner_nis_gate: 9.21`：二维 NIS 门限。
- `corner_max_variance_scale: 25.0`：方差放大上限。
- 方差倍率为 `clamp(NIS/gate, 1, max_scale)`，只作用于异常端点。通过 D R D 缩放完整协方差，权重在所有迭代轮保持不变。
- 一块板的异常角点也会污染 IPPE 深度差，因此该深度差按本板最大方差倍率同步降权。
- 不删除整块装甲板，不平滑最终命令，不改变关联规则。

这不是异常的绝对判定：模型误差、真实突变运动也可能产生大创新。参数需要结合日志和场景验证。

## 噪声对照

同板命令抖动指标：连续三帧都为 Tracking、规划有效且选板编号不变时，`abs(yaw[t]-2*yaw[t-1]+yaw[t-2])` 的 P95，单位度/帧²。该指标只是平滑程度，不等于瞄准精度。

预测误差指标：100 ms 外推板位与未来原始 PnP 的差异中位数/P95，单位米。PnP 不是地面真值，尤其在多解视角下，仅用于相同录像的相对比较。

| 配置 | 前334帧抖动P95 | 后1584帧抖动P95 | 前段预测差异 中位/P95 | 后段预测差异 中位/P95 |
| --- | ---: | ---: | ---: | ---: |
| 原 Qyaw=30，sigma=6.32 | 0.27314 | 0.29063 | 0.07094 / 0.25154 | 0.07357 / 0.25543 |
| Qyaw=15，sigma=6.32 | 0.26321 | 0.28147 | 0.07062 / 0.25223 | 0.07296 / 0.25559 |
| Qyaw=15，sigma=8 | 0.22602 | 0.24728 | 0.07201 / 0.24851 | 0.07401 / 0.24978 |

另扫描了单独 sigma=8、sigma=5 和端点 NIS 门限 5.99。此段录像的端点 NIS 均未越门，降权次数为 0；这些正常波动不会被强行当成坏点。坏点降权效果另由注入单端点偏移的回归测试验证。

后段三组配置均为 1579 个 Tracking 帧、0 次重置。采用小幅降 Qyaw 至 15，保留 sigma=6.32；改动幅度有限，不宣称消除全部视觉小跳动。
