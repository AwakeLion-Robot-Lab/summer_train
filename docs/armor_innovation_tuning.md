# 装甲板创新诊断与噪声对照

2026-11-05，录像 `video/3m_high`，YOLOv5 `model/armor_model/yolov5.xml`，当前角点精修、标定和规划配置。前 334 帧用于选参数，334–1917 帧用于后续片段验证。两段分别初始化跟踪器；后段不是独立场景，不能替代跨场地验证。

## 逐帧记录

```bash
xmake build track_diag
build/linux/x86_64/release/track_diag video/3m_high \
  -c=config/camera_config.yaml -m=model/armor_model/yolov5.xml \
  --config=config/auto_aim.yaml --scan-step=10 --out=/tmp/armor_innovation
```

`innovation.csv` 每个关联端点一行：帧号、时间、物理板编号、左右灯条、是否独立灯条、端点身份、先验像素创新 du/dv、原始二维 NIS、最终方差倍率。

`innovation_frames.csv` 每帧一行：本帧是否实际更新、关联完整板数量、独立灯条数量、端点数量、降权端点数量和深度差方差倍率。无更新时数量为零，不重复上一帧的诊断。

实机遥测在 `ekf.corner_innovations` 中提供相同端点信息；`auto_aim_test_armor` 的遥测包含 `corner_innovations`。`innovation_updated` 标记数据是否来自本帧。

## 降权规则

每个灯条观测有四维像素端点。在更新前计算 r 和 S=HPHᵀ+R，分别对上下端点的二维边缘分布计算 NIS。使用先验值，不拿迭代后的残差决定权重。

- `robust_corners: true`：收敛后启用端点降权；初始化阶段只记录，避免初始状态误差抑制正常收敛。
- `corner_nis_gate: 9.21`：二维 NIS 门限。
- `corner_max_variance_scale: 25.0`：方差放大上限。
- 方差倍率为 `clamp(NIS/gate, 1, max_scale)`，只作用于异常端点。通过 D R D 缩放完整协方差，权重在所有迭代轮保持不变。
- 一块板的异常角点也会污染 IPPE 深度差，因此该深度差按本板最大方差倍率同步降权。
- 不删除整块装甲板，不平滑最终命令，不改变关联规则。

这不是异常的绝对判定：模型误差、真实突变运动也可能产生大创新。参数需要结合日志和场景验证。

## 噪声对照

同板命令抖动指标：连续三帧都为 Tracking、规划有效且选板编号不变时，`abs(yaw[t]-2*yaw[t-1]+yaw[t-2])` 的 P95，单位度/帧²。该指标只是平滑程度，不等于瞄准精度。

预测误差指标：100 ms 外推板位与未来原始 PnP 的差异中位数/P95，单位米。PnP 不是地面真值，尤其在多解视角下，仅用于相同录像的相对比较。

| 配置 | 前334帧抖动P95 | 后1584帧抖动P95 | 前段预测差异 中位/P95 | 后段预测差异 中位/P95 |
| --- | ---: | ---: | ---: | ---: |
| 原 Qyaw=30，sigma=6.32 | 0.27314 | 0.29063 | 0.07094 / 0.25154 | 0.07357 / 0.25543 |
| Qyaw=15，sigma=6.32 | 0.26321 | 0.28147 | 0.07062 / 0.25223 | 0.07296 / 0.25559 |
| Qyaw=15，sigma=8 | 0.22602 | 0.24728 | 0.07201 / 0.24851 | 0.07401 / 0.24978 |

另扫描了单独 sigma=8、sigma=5 和端点 NIS 门限 5.99。此段录像的端点 NIS 均未越门，降权次数为 0；这些正常波动不会被强行当成坏点。坏点降权效果另由注入单端点偏移的回归测试验证。

后段三组配置均为 1579 个 Tracking 帧、0 次重置。采用小幅降 Qyaw 至 15，保留 sigma=6.32；改动幅度有限，不宣称消除全部视觉小跳动。

## 已知真值响应测试

```bash
xmake build eskf_target_smoke
build/linux/x86_64/release/eskf_target_smoke
build/linux/x86_64/release/eskf_target_smoke --noise-response
```

合成真值为横向 0.7 Hz、振幅 0.15 m 的正弦运动，同时整车以 1.8 rad/s 旋转；像素端点加入确定性的 1.5 px 波动。800 帧、10 ms 间隔，舍弃前 2 秒，比较 100 ms 后横向位置预测与真值。位置滞后通过 0–200 ms 的误差最小平移估计，分辨率 10 ms。

| 配置 | 100ms横向预测RMSE（m） | 位置滞后（ms） |
| --- | ---: | ---: |
| Qyaw=30，sigma=6.32 | 0.02177 | 0 |
| Qyaw=15，sigma=6.32 | 0.02113 | 0 |
| Qyaw=30，sigma=8 | 0.02355 | 0 |
| Qyaw=15，sigma=8 | 0.02280 | 0 |

没有检测到额外 10 ms 级位置滞后，不代表所有运动条件下都零滞后。更大 R 的配置因合成外推误差增加而未采用。

单端点注入测试同时检查：正常数据开关等价、收敛前不降权、正常端点权重不变、异常更新对状态的拉动减小、协方差半正定、派生深度差同步降权、快照诊断保留及重置清理。
