# 靶板四点的外圈约束

本文记录圈层约束首次接入时的实现和对照。后续的亮带中心线精修见
[外圈亚像素精修](rune_target_ring_subpixel.md)；复现本文的历史对照时需额外设置
`rune.detector.target_ring_subpixel: false`。

2026-11-14 另修复了断续 LED 被误判为无外圈的问题，新增有界连接重试及
`ring_reconnect` / `ring_no_contour` 诊断，见上述精修文档的现场修复记录。
以下统计保留首次实现时的历史结果。

针对网络将靶板的 `top / left / right / bottom` 在同心大小圈之间切换的问题。
普通 NMS 只按分数去重，不能确定物理圈层；对不同圈直接融合还会产生两圈之间的坐标。

## 配置与处理

工程配置开启：

```yaml
rune:
  detector:
    lock_target_ring: true
  geometry:
    radius_m: 0.70
    armor_half_width_m: 0.15
    armor_half_height_m: 0.15
```

几何尺寸沿用配置中的圆靶直径 0.30 m、R 到靶心 0.70 m。
`KeypointDetectorConfig::load` 和实机配置入口都读取这组尺寸；直接调用三参数
`fromYaml(detector, base_dir, geometry)` 时同样校验。开启时要求尺寸有限、为正，
靶板宽高半径相差不超过 5%，靶板半径小于 R 到靶心距离的一半。缺省关闭，
设 `lock_target_ring: false` 恢复旧的检测后处理及有效性策略。

NMS 的排序、分组和模式筛选保持原有约定。开启后，同组候选任一对可靠对点的
直径相对获胜候选变化超过 10% 时，不参与坐标融合。

每组最终候选在原图局部 ROI 中做独立图像检查：

1. 用红蓝通道差的绝对值与 Otsu 分割提取发光像素，闭运算连接离散 LED。
2. 对外轮廓凸包拟合椭圆，筛除中心偏离、退化形状及径向尺寸与物理比例不符的候选。
   径向半径允许相对 `图像中 R 到靶心距离 × 0.15 / 0.70` 偏差 15%。
3. 拟合只能提供候选；原始、未经闭运算的像素必须支持至少 24/32 个圆周角区间。
   同时检查凸包拟合误差和内部亮区占比，避免将短弧或实心亮斑当成整圈。
4. 在通过检查的候选中取最大椭圆，把四个语义方向与同一椭圆求交。
   保留网络给出的投影方向，允许径向和切向在图像中不正交；圈层半径由图像确定。

圈层检查要求至少三个靶板点及 R 可靠，用可靠对点的中点确定搜索中心；一对点
有弱点时用该方向剩余可靠点与中心确定方向。只更新原本可靠点，不提升弱点。
失败时保留原始坐标作为 ROI
种子，将四个靶板点的 `point_valid` 清零；R 的坐标、可靠性、类别和全部原始
分数保留。不会删除网络候选或提高弱点分数。大符已激活叶片可能只有灯臂，
跳过圆靶检查，仍按原来的灯臂辅助观测处理。

`ImageRefiner` 对连续两次通过圈层检查的同类靶板，还会比较独立图像配准后
的两组对点直径。相差超过 `max(2 px, 8% × 传递后的直径)`，或逐点运动残差
超过原有门限时，本帧四点失效，避免把错误圈层低通进正常坐标。
真实缩放、平移和旋转先由图像配准补偿，再做该检查。

所有目标圈均失败时，配准历史最多保留到原有 `max_gap_s`（工程为 0.2 s），
不把失败观测写成下一帧的参考，也不将历史靶板坐标作为本帧检测输出。
超过时限、模式/颜色切换、时间异常和画幅改变会重置历史。

`Processor` 跳过被标记为圈层失败的候选。没有其他可靠未激活靶板时，返回
`NoContour` 并停止本帧控制，按原有短时丢观测规则保留有界历史；不会将圈层失败
送入 PnP 后触发立即清空全部运动历史。长时间没有恢复可靠观测仍会重新预热。

诊断：`ring_ok` 是单帧通过的靶板数，`ring_reject` 是单帧失败数，
`ring_motion_reject` 是后续跨帧检查的拒绝数。前两个在检测器诊断中，
最后一个在实机每秒图像精修日志及 `rune_detect` 日志中。

## 适用范围

局部图像半径限定为 6～200 原图像素，需要未被画面截断的 ROI，以及足够多的
真实发光圆周。尺寸比例筛选使用局部近似投影关系；严重透视、过曝、暗光、
外圈大面积遮挡或并非圆靶的设备可能被拒绝。邻近圈的间距小于尺寸容差、且
首次观测就缺少真正外圈时，无法仅凭本检查保证圈层身份。

椭圆中心及发光边缘也可能有固定定位偏差；需要与实测 0.30 m 对应的物理边界
核对后评估绝对位姿精度。本次没有新增模型推理，没有重训网络，也没有进行实弹验证。
